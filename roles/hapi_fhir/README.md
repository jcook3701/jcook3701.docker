# HAPI FHIR

[HAPI FHIR](https://github.com/hapifhir/hapi-fhir) is an open-source, Java-based reference implementation for the HL7 FHIR (Fast Healthcare Interoperability Resources) standard. It provides libraries and server frameworks to build healthcare applications, parse medical data structures, and run compliant REST servers for exchanging electronic health records.
